# Dĩ bất biến, ứng vạn biến

Website trình chiếu Chương 2 · Chủ đề 3, môn VNR202 (Lịch sử Đảng Cộng sản Việt Nam).

- Mở `index.html`, dùng phím ← → để chuyển slide, F để toàn màn hình.
- Ảnh trong `img/` lấy từ Wikimedia Commons, thuộc phạm vi công cộng; nguồn ghi dưới mỗi ảnh.
- Sản phẩm sáng tạo: bảo tàng 3D kiểu kinh thành ở `bao-tang/` (đường dẫn `/bao-tang`). Đi bằng W A S D hoặc phím mũi tên, kéo chuột để nhìn, bấm vào ảnh để xem sa bàn 3D, phím 1–4 để đi nhanh tới từng khu.
